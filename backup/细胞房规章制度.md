# 细胞房规章制度

2024年12月24日（更新中）

::: danger 特别注意
禁止私自带外人进入，所有使用细胞房的同学需经过孟老师同意！！！
:::

## 一、耗材
1. 公用耗材：手套，口罩、垃圾袋、卷纸由我们实验室统一提供，大家不需要准备。卷纸喷酒精后放在细胞房紫外柜中备用。
2. 自用耗材：各自使用，备用耗材放在外间盒子里，已拆分和马上要使用的耗材放在内间紫外柜子里。已经拆分的耗材需扎紧存放，超净工作台内仅存移液抢、放枪架、垃圾桶以及试管架，不允许放耗材。做完实验开超净台紫外灯（UV）杀菌。
3. 从紫外柜里拿出的耗材，需要喷酒精后，拿进超净工作台。超净台使用前需喷酒精擦拭后使用。
4. 即将使用的耗材酒精喷洒后，拿进细胞房内紫外柜待用，缓冲间不允许堆放耗材。

## 三、卫生

1. 每周值日生负责打扫细胞房、缓冲区，擦拭所有地面、桌面以及仪器表面（用白色纱布），外间一个月打扫一次；配酒精，灭菌枪头，灭菌水，检查无水乙醇剩余量并及时告知负责人。

2. 细胞房抹布需要分开，用完后统一挂在缓冲间消杀。

3. 每周值日生完成值日后，群里打卡。

    值日分组情况如下：

    (1). 陈玉、尹诗雨、贾硕磊

    (2). 潘瑾如、刘宛茹

    (3). 高雅慧、张雅洁

4. 实验服值日生每周进行清洗，准备四件，不放多余实验服，备用的四件实验服清洗晾干后放在细胞房紫外柜，下次更换。

## 五、用电安全

实验结束，关闭空调、显微镜、离心机、水浴锅所有仪器，并拔掉相应插头

## 六、预约与登记

使用前一天在群里预约，使用完毕扫码登记。

## 七、检查监督

孟老师不定期检查，出现问题的学生实验停止一个月，再出现禁止实验。
